Color Rally

Controls and access

Use Tab to reach Start and press Enter. Start focuses the game canvas. After the score appears, press Space to score and change the canvas color. If focus moves away, Tab back to the canvas or click it. The score is also shown in text.

Fullscreen is optional. Tab to Fullscreen and press Enter. Press Escape to leave it. This build requires a physical keyboard and a desktop browser with WebGPU. Touch controls are unavailable.
