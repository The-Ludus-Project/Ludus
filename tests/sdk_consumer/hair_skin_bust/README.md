# Hair and skin qualification in a standalone game (#1400)

A Qt-free installed-SDK app that draws one Editor-saved, cooked character-bust
World through the packaged forward-lit (hair cards) and clustered-deferred (skin)
graphs, for comparison with the Editor on the same exported scene. `capture.cpp`
is the app and `verify.py` the reproducible driver. The canonical documentation
is [Qualify hair and skin in a standalone game](../../../docs/development/hair-skin-standalone-qualification.md).
